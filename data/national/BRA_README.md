# Brå-moduuli (Ruotsi)

**Määritelmä:** syntymämaa / inrikes–utrikes bakgrund (vanhempien syntymämaa mukaan lukien); ei kansalaisuus (NAT/FOR).

Ei Eurostat NAT/FOR. Ei EU-aggregaattiin.

Lähde: Brå (Brottsförebyggande rådet). https://bra.se/om-bra/om-webbplatsen/data-fran-bra

Tiedosto (jos ladattu käsin): `data/national/se_bra.csv`.
Meta: `output/tables/national/bra_meta.csv`.

Brå-moduuli: määritelmä = syntymämaa / bakgrund, ei kansalaisuus. Julkista API:a tuomituille × kansalaisuus ei ole. Brån 2021-tyyppinen raportointi koskee epäiltyjä ja inrikes/utrikes bakgrund. Sijoita käsin ladattu CSV/XLSX: data/national/se_bra.csv. PDF-lukuja ei kopioida. Ei EU-aggregaattiin, ei K1-selittäjäksi.
